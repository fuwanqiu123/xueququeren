# 湘潭市学区地图查看工具

为湘潭市中小学教师和家长提供的移动端学区范围确认工具，支持在手机浏览器中直接打开查看，无需安装。

---

## 📋 功能清单（V2.0）

### 一、基础功能

#### 1. 双模式切换
- **中学学区模式**：加载 `data/middle/` 目录下的中学学区数据（24所学校）
- **小学学区模式**：加载 `data/primary/` 目录下的小学学区数据（75+所学校）
- **一键切换**：顶部栏"切小学/切中学"按钮快速切换
- **URL直达**：支持通过 `?mode=middle` 或 `?mode=primary` 参数直接打开指定模式

#### 2. 地图底图
- **天地图集成**：使用天地图服务作为底图（矢量/影像双模式）
- **多KEY轮换**：内置9个天地图密钥，自动轮换避免配额超限（每KEY上限4900次/日）
- **双底图切换**：支持矢量地图和影像地图一键切换
- **默认视图**：湘潭市中心点（112.9441, 27.8297），默认缩放级别11

---

### 二、数据展示

#### 3. 学区数据加载
- **GeoJSON格式**：支持标准GeoJSON格式的学区边界数据
- **FeatureCollection**：支持包含多个特征的集合
- **MultiPolygon支持**：自动识别并高亮一个学校的所有多边形（非连续学区）
- **索引文件**：通过 `index.json` 批量加载数据
- **动态渲染**：每个学区自动分配不同颜色（20色循环），便于区分

#### 4. 行政区边界
- 显示湘潭市行政区划边界（虚线样式）
- 作为学区分布的地理参考

#### 5. 标签显示
- 学校名称标签：在缩放级别≥12时显示
- 标签颜色与学区颜色对应

---

### 三、交互功能

#### 6. 点击选中（智能重叠处理）
- **单学区选中**：点击单个学区高亮显示
- **重叠区域处理**：点击重叠学区时，同时选中该位置的所有学区
- **全部高亮**：一个学校的所有多边形（MultiPolygon）会被同时高亮
- **平滑动画**：选中后自动飞移到学区位置（500ms过渡）

#### 7. 选中学校列表面板
- **实时显示**：左侧面板显示已选中的所有学校
- **颜色标识**：每个学校显示对应的颜色标记
- **数量统计**：显示当前选中的学校数量
- **快速定位**：点击学校名称可飞移到该学区
- **单独移除**：点击"×"可从列表中移除单个学校的选中状态
- **移动端适配**：移动端自动调整到底部显示

#### 8. 搜索功能
- **实时搜索**：输入时即时过滤学校名称
- **模糊匹配**：支持部分匹配，不区分大小写
- **结果限制**：最多显示10条搜索结果
- **一键定位**：点击搜索结果直接飞移到对应学区
- **关键词高亮**：搜索结果中高亮匹配的文字

---

### 四、视图控制

#### 9. 地图导航
- **缩放控制**：右下角"+/-"按钮缩放
- **全览按钮**：一键适配到所有学区范围
- **平滑动画**：所有飞移动作都有500ms平滑过渡

#### 10. 清除高亮
- **清除按钮**：一键清除所有高亮状态
- **恢复默认**：所有学区恢复淡化样式（半透明灰色）

## 快速开始

### 1. 配置天地图密钥

编辑 `config.js` 文件，已内置9个备用密钥，如需更换：

```javascript
const CONFIG = {
    TIANDITU_KEYS: [
        '您的天地图密钥1',
        '您的天地图密钥2',
        // ...
    ],
    // ...
};
```

**申请天地图密钥**：
1. 访问 [天地图开发者中心](https://console.tianditu.gov.cn/)
2. 注册并登录账号
3. 创建新应用，获取密钥

### 2. 准备数据

#### 数据目录结构
```
data/
├── xiangtan_boundary.geojson     # 湘潭市行政区划边界
├── middle/                       # 中学学区数据
│   ├── index.json               # 文件索引
│   └── *.geojson                # 学校数据文件
└── primary/                      # 小学学区数据
    ├── index.json               # 文件索引
    └── *.geojson                # 学校数据文件
```

#### 数据格式规范

每个学校的 GeoJSON 文件格式如下：

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Polygon",
        "coordinates": [
          [
            [112.90, 27.87],
            [112.91, 27.87],
            [112.91, 27.88],
            [112.90, 27.88],
            [112.90, 27.87]
          ]
        ]
      },
      "properties": {
        "name": "学校名称",
        "district": "所属区县",
        "address": "学校地址"
      }
    }
  ]
}
```

**支持的几何类型**：
- `Polygon`：单个多边形
- `MultiPolygon`：多个不连续多边形（一个学校多个校区/分散学区）

### 3. 部署使用

#### 方式一：本地服务器（推荐）
```bash
# 使用 Python
python -m http.server 8081

# 使用 Node.js
npx http-server -p 8081

# 然后访问 http://localhost:8081
```

#### 方式二：部署到 Web 服务器
将项目文件夹上传到任意 Web 服务器（Nginx、Apache 等）即可。

### 4. URL 参数

支持通过 URL 参数指定默认模式：

- 打开即显示中学学区：`index.html?mode=middle`
- 打开即显示小学学区：`index.html?mode=primary`

## 常见问题

### Q: 地图显示空白？
A: 请检查：
1. 天地图密钥是否正确配置
2. 网络连接是否正常
3. 浏览器控制台是否有错误信息

### Q: 学区数据不显示？
A: 请检查：
1. 数据文件路径是否正确
2. GeoJSON 格式是否规范
3. `index.json` 文件是否存在且内容正确

### Q: 如何转换坐标系？
A: 如果数据是其他坐标系（如 CGCS2000），可以使用 QGIS、ArcGIS 等工具转换为 WGS84（EPSG:4326）。

### Q: 点击重叠学区如何处理？
A: 工具会自动识别点击位置的所有学区，并将它们全部添加到选中列表。您可以在左侧面板中看到所有选中的学校。

## 📄 中学学区 PDF 批量生成器（Web 图形界面）

项目还提供了一套基于 Flask 的 Web 图形界面，用于把合并后的中学学区 GeoJSON 批量生成带天地图底图的 PDF 确认图（每所学校一页 A4 横版）。

### 快速启动

- **Windows**：双击 `python-tools/启动中学学区PDF生成器.bat`，浏览器将自动打开操作页面。
- **macOS / Linux**：
  ```bash
  bash python-tools/启动中学学区PDF生成器.sh
  ```

打开后访问 `http://127.0.0.1:5000/` 即可使用。

### 主要功能

- 选择或上传 GeoJSON 学区文件
- 配置天地图服务端 Key（支持多 Key 轮换）
- 调整出图参数：视野外扩、DPI、字体、底图类型、注记开关等
- 实时查看运行日志和进度
- 完成后一键打包下载所有 PDF

### 环境依赖

```bash
pip install -r requirements.txt
```

详细说明见 `python-tools/GUI使用说明.md`。
